# 🐍 SnakeSense

A production oriented AI engineering project that combines Computer Vision, Retrieval Augmented Generation (RAG), and LLMs for snake species identification.

## Objectives

- Build a robust image classification pipeline
- Learn production style ML workflows
- Implement RAG for verified knowledge retrieval
- Build an end to end AI backend
- Deploy a complete AI application

## Technologies

- Python
- APIs
- PyTorch
- OpenCV
- FastAPI
- LangChain
- ChromaDB
- Hugging Face
- Docker

## Project Status: 
🚧 Active Development. Building the project incrementally while documenting each stage from dataset engineering to deployment.
